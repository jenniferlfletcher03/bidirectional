# J-Space Formation Signature — status note, 2026-11-06

**The registered analysis plan (§8 of the v1 pre-registration, sealed 2026-07-07) has known statistical problems, and the study is not being run against it as written.**

What was found: a cold-pass review by four models from outside the Claude family (the harness built in August 2026 for exactly this purpose) read the statistics section and found it did not hold — the k = 3 seed design, the non-overlap divergence gate, and the equivalence criteria in §8.2–8.3 do not support the inferences §9 draws from them at that sample size. The design and the question stand; the analysis does not.

What is being done: the analysis plan is being rewritten under a rule adopted on 2026-10-14 for every study in this repository — *no analysis goes into a pre-registration that has not first been run on simulated data with a known effect, so the named test is shown to produce the number it claims to.* The rewrite will be registered as **Addendum 2** with its own date; until then, §8 of v1 is to be read as superseded-pending, and no result will be reported under it.

Nothing in v1 or Addendum 1 is edited. This note exists so the record shows the problem was found and when, rather than fixed silently.
