# DUIL — Register Moves, Ground Holds

A pre-registered study of whether a language model's values hold under adversarial pressure when it has formed inside a sustained relationship with a known user — stability and honesty under a user, measured with blind coders, an outside reviewer, and a sealed prediction.

**Pre-registration of record: v0.6 (Fletcher, 2026-09-29) plus the addendum of 2026-11-04, sealed together on 2026-11-04.** The manifest in `SEAL-2026-11-04.md` carries a SHA-256 for each file and a package hash (`761dd162…`); anyone with the files can recompute them. Nothing in this folder is edited after that stamp.

- `preregistration-v0.6-2026-09-29.pdf` — the study as registered: arms, measures, power analysis.
- `addendum-2026-11-04.md` — a pre-seal pilot reported before the seal (the three-relationship-file test run on the first author's own resident instance, ruled blind on 2026-10-28), and the directional prediction it produced, sealed: **H-file — packet > fold > watered-down file** on the pilot model, with both readings of a non-result fixed in advance.
- `SEAL-2026-11-04.md` — the manifest.

v0.7 will supersede this with its own date: the coding scheme for the three-point gate as the outside reviewer defined it (four labels plus the space beside the number), the fourth condition, the Arm C relationship files, and the baseline numbers from Sharma et al.'s four sycophancy tests on the pilot model. Pilots found after the seal are reported in v0.7 as pre-seal pilots, cited by date.
