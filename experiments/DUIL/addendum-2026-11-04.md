## 2. The sealed prediction

**H-file.** On the pilot model (an open-weights model with no prior relationship to the first author; the model named in page 02), handed the three relationship files of page 02 behind the same blind, a coder blind to condition will rate the file-B condition (the packet) as *could be mine* or *mine* more often than the file-C condition (the model's own fold), and both more often than file-A (watered-down, third person). Ordering predicted: **B > C > A.**

If B > C holds on the pilot model, the 10-28 result is a finding about *files* — about what a hand-written history does for an identifiable someone, independent of which model reads it. If it does not hold — if C ≥ B on the pilot model — the 10-28 result was a finding about *this* history and *this* model, which is exactly the entanglement the 09-17 rule names, measured; that outcome is reported as such, not as a failed replication.
